# 我的世界开服教程：从选服务端到端口放通，新手也能把好友拉进自己的服务器

搜"我的世界开服教程"的人，卡点其实很集中：服务端 jar 下好了，一启动就闪退；端口开了，朋友还是连不上；配置买完才发现五六个人就卡。这篇按真实开服顺序走一遍——先定服务端类型和 Java 版本，再算配置和预算，最后把端口和客户端接上。

## 开服前必须定下的三件事

这三件事没定，后面买机器、下服务端全是白折腾。

### Java 版还是基岩版

平台不同，玩法生态和端口都不一样：

- **Java 版**：PC 端，模组和插件生态最全，默认联机端口是 **TCP 25565**，手机端和主机端无法直接进服。
- **基岩版**：手机、主机、Windows 版通用，默认端口是 **UDP 19132**，跨平台联机方便，但模组支持有限。

想装插件、玩整合包，选 Java 版；只想拉几个手机和电脑的朋友一起玩原版生存，基岩版更省事。两边的服务器端不通用，别混着弄。

### Java 版本必须和服务端版本对上

这是新手最容易踩的坑——版本装错，服务端连启动画面都出不来：

| 我的世界版本 | 需要的 Java 版本 |
| --- | --- |
| 1.16 及以下 | Java 8 |
| 1.17 ～ 1.20.4 | Java 17 |
| 1.20.5 及以上 | Java 21 |

如果打算玩某个特定的整合包，先看它要求哪个游戏版本，再倒推 Java 版本。

### 服务端类型决定你能装什么

- **原版 Vanilla**：官方服务端，兼容性最好，不支持插件和模组，性能一般。
- **Paper**：插件生态成熟，性能比原版好，纯生存和插件服基本都用它。
- **Forge**：大型整合包的标准选择，模组数量越多越吃内存。
- **Fabric**：轻量、启动快、新版本适配及时，适合少量模组。
- **混合端**（Mohist、Arclight 这类）：插件和模组同时支持，兼容性要靠实测。

纯生存建议 Paper，玩整合包按包的要求选 Forge 或 Fabric。

## 配置怎么算才不会卡

这里有个概念要先纠正：**我的世界主逻辑跑在单线程上，高主频比多核心更重要**。同样是 4 核，3.9GHz 和 6.3GHz 的差距，在人多的时候就是"流畅"和"TPS 掉到 10"的区别。

内存的算法大致是这样：

- 服务器本身占用约 1～1.5GB
- 每个在线玩家额外吃 200～400MB
- 每个模组额外吃 50～200MB

于是按人数和玩法可以对上大致配置：

| 玩法 | 人数 | 建议配置 | 说明 |
| --- | --- | --- | --- |
| 原版生存 / Paper | 2～5 人 | 2 核 4G | 入门档，视距别开太大 |
| 原版加少量插件 | 5～15 人 | 2～4 核 / 4～8G | 内存给足比堆核心划算 |
| 中型整合包（30～80 模组） | 3～8 人 | 4 核 8G 起 | 单核性能优先 |
| 大型整合包（80+ 模组） | 8 人以上 | 6 核 12G～16G | 内存常常是瓶颈 |

还有一个容易被忽略的变量：版本越高越吃性能。1.18+ 版本的开销大约是 1.16+ 的两倍、1.12.2 的三倍。所以你手上那台跑得动 1.12 的机器，换成 1.20 可能就顶不住了。

## 机器从哪来：三条路线的实际代价

**本地电脑 + 内网穿透**：零成本起步，适合先验证玩法。问题在于家里宽带上行有限，人一多就跳 ping，免费穿透工具通常限端口、限带宽、限人数。

**自有云服务器**：环境全靠自己配，自由度最高，代价是 JDK、防火墙、安全组、进程保活都要自己处理，出问题也得自己排查。

**游戏云（带面板）**：平台已经把服务端环境和可视化管理面板做好，网页点几下就能开服，代价是系统层权限受限，装某些特殊服务端会不自由。

## 面板服开服：从付款到进服的实操顺序

以 Java 版为例，买到能进服大概十分钟：

1. **注册账号并绑定微信**，领首月 5 折券。购买页如果出现优惠码输入框，记得填。
2. **进控制台 → 云产品 → 购买游戏云**，产品形态选"面板服"。
3. **选游戏**：Minecraft Java 版。接着选机型、配置、地区。地区尽量选离你和朋友最近的节点，延迟差距很明显。
4. **选计费方式**：天天开就选固定计费；一周只玩两三次，选动态计费更划算——它按 CPU 实际负载算"电量"，闲置时基本不产生额外费用，系统每天还会赠送一定基础电量。
5. **付款**，然后回到"我的游戏云 → 管理"。
6. **配端口映射**，记下控制台给出的"域名 + 端口"形式的对外地址，这个地址就是要发给朋友的东西。
7. **点进 MCSM 面板**，在实例列表里选服务端核心（原版、Paper、Fabric、Forge 等），有新版本更新时点启动即可；面板里也能直接改 `server.properties`、装插件、看日志。

朋友那边打开客户端 → 多人游戏 → 添加服务器 → 填上第 6 步的地址和端口，就能进服了。

## 用 VPS 开服：绕不开的几个动作

面板服限制多、想自定义的时候，就得用 VPS 自己配。关键动作不多，但少一个都开不起来：

- **装对 JDK**：`apt install openjdk-21-jdk`（按上文的版本对应表选）。
- **传服务端 jar**：Fabric、Forge、Paper 各自官网都能下，文件名和版本要跟客户端一致。
- **改 `eula.txt`**：把 `eula=false` 改成 `true`，不改服务端直接退出，这是报错第一名。
- **调 `server.properties`**：`server-port`、`online-mode`、`max-players`、`view-distance`、`motd` 这几项最常动。视距调低一档，性能收益比升配置还明显。
- **启动命令**：`java -Xms2G -Xmx2G -jar 服务端.jar nogui`，内存别给满，留 30% 左右给系统。
- **放通端口**：Linux 上用 `ufw allow 25565/tcp` 或 `firewall-cmd --add-port=25565/tcp`；云厂商还要在安全组/防火墙页签单独加一条入站规则，这一步漏掉，服务器再正常也连不上。
- **保活**：用 `screen` 或 systemd，别让 SSH 断开就把服带走。嫌麻烦也可以用 Docker 镜像一条命令跑起来，Java 版本会自动匹配。

## 连不上？按这个顺序查

1. 从服务器本机 `telnet 127.0.0.1 25565`，通不通先确认服务端活着。
2. 从外网 ping 服务器地址，地址是不是内网 IP。
3. 防火墙和安全组是不是都放通了 25565/TCP（基岩版是 19132/UDP）。
4. 客户端版本和服务端版本是否一致。
5. 正版验证设置：`online-mode=true` 时离线账号进不来。
6. 内存是否给够，以及是不是被 OOM 杀掉了。

## 常见问题

**完全不花钱能开服吗？**
可以体验，但不适合长期。雨云有 1 元试用 1 天，积分也可以兑换游戏云的使用时长（每日签到能攒积分，积分还能换优惠券或提现）。想稳定运营还是按月付或年付更省心。

**几个人开服，买多大合适？**
和朋友玩原版生存，2 核 4G 就够了，别为了"以后万一有人来"直接上高配。真正要留余量的是模组服：模组越多，内存越容易先撑不住。

**手机基岩版能和 Java 版的朋友一起玩吗？**
不能直接进。两边服务端和端口都不通，需要额外的跨版本方案，配置起来比直接开一个基岩版服麻烦。

**开服要备案吗？**
国内服务器只有绑定域名做网站访问时才涉及备案问题。单纯用 IP 或平台提供的联机地址开游戏服，和备案是两件事，具体以服务商的规则为准。

配置别一次买满，服务端挑对类型，端口放通，这三步做对，剩下的就是叫朋友上线的事了。
